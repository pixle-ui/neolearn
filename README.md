# NeoLearn

🔗 **Live site:** [neolearn-a09.pages.dev](https://neolearn-a09.pages.dev)

A free, multi-platform tech tutorial site. Every tutorial shows commands specific to YOUR platform — Linux, Android, Mac, Windows, or iOS.

## What's inside

- **32 tutorials** across 6 categories: AI, Hacking, Android, Streaming, Networking, Coding, Linux, iOS, Mac
- **Platform-aware** — switch platforms mid-tutorial and the steps update live
- **Favorites** — save tutorials, stored locally
- **Progress tracking** — check off steps as you complete them
- **Copy buttons** — one tap to copy any command
- **Sidebar search** — filter tutorials instantly

## Built with

Plain HTML, CSS, and JavaScript. No frameworks. No build tools. Hosted free on Cloudflare Pages.
