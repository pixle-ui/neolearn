What is this?

NeoLearn is a collection of step-by-step tutorials for running cool tech — AI models, Termux, Linux, VPNs, security tools, and more — on any device. Every tutorial gives you the exact commands for YOUR platform.

Features

  • 📱 Multi-platform — Linux, Android, Mac, Windows, iOS
  • 📋 One-tap copy for every command
  • ⭐ Save favorites
  • ✅ Track your progress step by step
  • 💯 100% free, no accounts, no tracking
  • 💾 Everything saves locally in your browser

Built with

Pure HTML, CSS, and JavaScript. No frameworks, no build step, no dependencies. You can host it anywhere for free.

  • Custom Fuzzy-Search Algorithm (Levenshtein Distance)
  • Vanilla JavaScript State Management
  • Responsive CSS Grid/Flexbox with Glassmorphism
